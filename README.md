# Футбол України — шаблони сторінок нової структури

Статичні HTML-шаблони всіх сторінок з вкладки «301 основа». Перегляд: відкрийте `index.html` (або GitHub Pages) — там список усіх сторінок.

## Структура

```
assets/css/main.css    усі стилі (кольори і шрифти — змінні на початку файлу)
assets/js/main.js      мобільне меню, прокрутка смуги турів
upl/                   хаб УПЛ
upl/news/              архів новин (пагінація /news/page/N/)
upl/news/{slug}/       шаблон статті
upl/table/             турнірна таблиця
upl/calendar/          календар по турах
upl/bombardyry/        бомбардири поточного сезону
upl/bombardyry/2025-2026/   архів сезону
persha-liga/ …         хаб, news, table, calendar, bombardyry
druga-liga/ …          те саме, таблиці й календар по групах А і Б
zbirna-ukrayiny/       хаб, news, calendar
transfery-ukrayiny/    рубрика-стрічка (без окремої /news/)
tools/build.py         генератор шаблонів (python3 tools/build.py)
```

## Як переносити у WordPress

| Сторінка | Шаблон WP | Звідки дані |
|---|---|---|
| `/{ліга}/` хаб | `category-{slug}.php` | 5 останніх записів рубрики (без пагінації) + віджети API |
| `/{ліга}/news/` | архів рубрики, правило перезапису `/{рубрика}/news/page/N/` | WP_Query по рубриці, 20 на сторінку |
| `/{рубрика}/news/{slug}/` | `single.php` | the_content; картка матчу, якщо до запису прив'язаний матч |
| `/{ліга}/table/` | `page-table.php` | API standings |
| `/{ліга}/calendar/` | `page-calendar.php` | API fixtures by season, відкривати на поточному турі |
| `/{ліга}/bombardyry/` | `page-scorers.php` | API topscorers |
| `/zbirna-ukrayiny/calendar/` | `page-calendar.php` | API fixtures by team |

Елементи з даними позначені атрибутом `data-source` (`api:…` — API, `wp:thumbnail` — мініатюра запису).

## Правила проти дублів

- На хабі максимум 5 новин, без пагінації. Пагінація тільки на `/news/page/N/`; старі `/{рубрика}/page/N/` — 301 туди.
- `/transfery-ukrayiny/news/` не створюється: 301 на `/transfery-ukrayiny/` до запуску трансферного хабу.
- Архів бомбардирів сезону створюється тільки після завершення сезону.

## Що замінити перед запуском

- Жовті блоки `.devnote` — службові, видалити.
- `.crest` (кружечок з літерами) — заглушка емблеми клубу, замінити на логотип з API (`team.image_path`).
- `.news__img` (газон) — заглушка фото, замінити на мініатюру запису.
- «Прізвище Ім'я» у бомбардирах — приклад, дані з API.
- Архів УПЛ 2025/26 перенесено зі старої сторінки як є (7 рядків) — замінити підсумковою таблицею сезону.
- Таблиці, календарі, новини — знімок сайту на 19.10.2026.
- Зверстана одна стаття (`upl/news/polissya-…/`); решта посилань на статті й пагінацію ведуть на адреси нової структури і запрацюють після перенесення у WP.

## Дизайн

- Шрифти: Unbounded (заголовки, табло, позиції) і Onest (текст, таблиці, назви команд), обидва з кирилицею, Google Fonts.
- Кольори: темно-синій `#13213c`, фон `#eef2f7`, посилання `#1c4fd6`, акцент жовтий `#ffd23f`.
- Логотип — SVG у шапці (м'яч на жовтому квадраті + «Футбол / України»).
- Зони таблиці: єврокубки — синя смуга, підвищення — зелена, плей-оф — жовта, пониження — червона.
- Адаптив від 360 px, видимий фокус клавіатури, `prefers-reduced-motion`.
- SEO: title, description, canonical, Open Graph, JSON-LD BreadcrumbList, FAQPage на хабах, NewsArticle у статті.
