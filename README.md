# Футбол України — шаблони сторінок нової структури

Статичні HTML-шаблони всіх сторінок з вкладки «301 основа». Відкрийте `index.html`: там перелік сторінок з посиланнями. Через GitHub Pages працює без збирання.

## Структура

```
assets/css/main.css    усі стилі (змінні кольорів і шрифтів на початку файлу)
assets/js/main.js      мобільне меню і прокрутка смуги турів
upl/                   хаб УПЛ
upl/news/              архів новин (пагінація /news/page/N/)
upl/news/{slug}/       шаблон статті
upl/table/             турнірна таблиця
upl/calendar/          календар по турах
upl/bombardyry/        бомбардири поточного сезону
upl/bombardyry/2025-2026/   архів сезону
persha-liga/ …         хаб, news, table, calendar, bombardyry
druga-liga/ …          те саме, таблиці та календар по групах А і Б
zbirna-ukrayiny/       хаб, news, calendar
transfery-ukrayiny/    рубрика-стрічка (без окремої /news/, див. нижче)
tools/build.py         генератор шаблонів (python3 tools/build.py)
```

## Як переносити у WordPress

| Сторінка | Шаблон WP | Звідки дані |
|---|---|---|
| `/{ліга}/` хаб | `category-{slug}.php` | 5 останніх записів рубрики (без пагінації) + віджети API |
| `/{ліга}/news/` | архів рубрики за правилом перезапису `/{рубрика}/news/page/N/` | WP_Query по рубриці, 20 на сторінку |
| `/{рубрика}/news/{slug}/` | `single.php` | the_content; картка матчу, якщо до запису прив'язаний матч |
| `/{ліга}/table/` | сторінка з шаблоном `page-table.php` | API standings |
| `/{ліга}/calendar/` | `page-calendar.php` | API fixtures by season; відкривати на поточному турі |
| `/{ліга}/bombardyry/` | `page-scorers.php` | API topscorers |
| `/zbirna-ukrayiny/calendar/` | `page-calendar.php` | API fixtures by team |

Елементи з даними API позначені атрибутом `data-source="api:…"`.

## Правила проти дублів

- На хабі максимум 5 новин і жодної пагінації. Уся пагінація тільки на `/news/page/N/`, старі `/{рубрика}/page/N/` ведуть 301 туди.
- `/transfery-ukrayiny/news/` не створюється: 301 на `/transfery-ukrayiny/` до запуску трансферного хабу.
- Архів бомбардирів створюється тільки після завершення сезону.

## Що замінити перед запуском

- Блоки `.devnote` (жовті примітки) — службові, видалити.
- Рядки «Прізвище Ім'я» у бомбардирах — приклад, у робочій версії дані з API.
- Архів УПЛ 2025/26 перенесено зі старої сторінки як є (там лише 7 рядків) — замінити підсумковою таблицею сезону.
- Таблиці, календарі та новини — знімок сайту на 19.10.2026.
- Посилання на статті і сторінки пагінації ведуть на реальні адреси нової структури; у шаблонах зверстана одна стаття (`upl/news/polissya-…/`), решта посилань відкриються після перенесення у WP.

## Дизайн

- Шрифти: Unbounded (заголовки, табло, позиції) і Onest (текст, таблиці), обидва з кирилицею, Google Fonts.
- Кольори: темно-синій `#13213c`, фон `#eef2f7`, посилання `#1c4fd6`, акцент жовтий `#ffd23f` (час матчу, поточний тур, фокус).
- Зони таблиці: єврокубки синя смуга, підвищення зелена, плей-оф жовта, пониження червона.
- Головний елемент хабу — «табло» з матчами наступного туру.
- Адаптив до 360 px, видимий фокус клавіатури, повага до `prefers-reduced-motion`.
- SEO: title, description, canonical, Open Graph, JSON-LD BreadcrumbList, FAQPage на хабах, NewsArticle у статті.
